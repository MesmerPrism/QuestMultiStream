Paste the current operator link from this host. Credentials stay in this window's session; a new app window may need the link again. Existing unresolved requests remain owned and are never replayed by installation.

Install on this device

Windows Edge or Chrome and Android Chrome: choose Install app in the browser menu when offered. iPhone Safari: open Share, choose Add to Home Screen, turn on Open as Web App if offered, then Add.

Installation needs HTTPS trusted by this device, or localhost on this device. A phone cannot use the PC's localhost; an ordinary LAN HTTP address is not a secure installation origin.

The host must remain reachable. There is no offline control or saved media. After closing and reopening, use Connect operator link if asked; installing the app does not save the link.
